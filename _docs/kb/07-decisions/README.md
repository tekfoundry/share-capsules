## Decision Template

```markdown
# ADR-XXXX: Decision title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

## Decision

## Rationale

## Consequences

## Alternatives Considered

## Related Documents
```

Superseded decisions should say what replaced them and link to the current KB
page. Draft exploration belongs in requirements, architecture, or plan docs
until it becomes an accepted decision.
