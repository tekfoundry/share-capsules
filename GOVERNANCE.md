# Governance

Share Capsules is sponsored and initially maintained by TekFoundry. During the MVP period, TekFoundry is the final decision maker for project direction, release timing, compatibility claims, and security posture.

## Decision Process

- Small implementation and documentation changes can be accepted through normal pull request review.
- Protocol, security, privacy, interoperability, or product-scope changes should be discussed in an issue or design document before implementation.
- Accepted tradeoffs and release decisions should be recorded in the relevant operations or design document.
- Compatibility claims require tests, fixtures, and documentation for the relevant versioned Capsule or CTX contract.

## Maintainer Responsibilities

- Keep the threat model and release evidence current.
- Avoid overstating what Capsule and CTX can protect.
- Review security-sensitive changes with extra care.
- Preserve public reviewability of protocol decisions.
- Keep contribution and vulnerability-reporting paths understandable.

## Independence And Ecosystem Goals

Capsule and CTX are intended to support compatible independent implementations and creator-selected providers over time. The current Share Capsules hosted service is the reference implementation and official MVP network, not a claim that the ecosystem must stay single-provider.
